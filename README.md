# Voxel Launcher

Minecraft Java-лаунчер на Python,Qt.

## Возможности

- Официальный каталог всех доступных Java-версий Mojang, включая релизы, снапшоты, alpha и beta.
- Установка клиента, библиотек, нативных файлов и ресурсов с проверкой SHA-1.
- Выбор основного загрузчика: Vanilla, Fabric, Forge, NeoForge, Quilt, LiteLoader.
- Создание, редактирование и дублирование сборок; индивидуальные настройки памяти, папки, Java и JVM.
- Установка модов из Modrinth с обязательными зависимостями.
- Импорт клиентских `.mrpack` формата Modrinth v1 и экспорт установленных модов/конфигураций обратно в `.mrpack`.
- Офлайн-аккаунты, OAuth Microsoft и Ely.by с шифрованием токенов AES-256-GCM.
- Скачивание ZIP-архива с готовыми файлами и скриптами запуска для Windows, Linux и macOS.

## Запуск веб-лаунчера

1. Укажите `DATABASE_URL` в `.env`.
2. Установите зависимости: `npm install`.
3. Примените схему: `npx drizzle-kit push`.
4. Запустите: `npm run dev` или `npm run build`.

Настройки, профили, аккаунты и задачи сохраняются в PostgreSQL. Файлы сборок — в `data/instances/`. Веб-сессия идентифицируется случайной HttpOnly-cookie; чужие профили недоступны. Для постоянной эксплуатации подключите durable volume для каталога `data/` и резервное копирование PostgreSQL. Очистка `data/` удаляет скачанные файлы, но не сбрасывает статус в БД: после очистки удалите и заново установите затронутые профили.

## Microsoft и Ely.by

Зарегистрируйте OAuth-приложение и задайте серверные переменные (см. `.env.example`):

- Microsoft: `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET`, `MICROSOFT_REDIRECT_URI`.
- Ely.by: `ELYBY_CLIENT_ID`, `ELYBY_CLIENT_SECRET`, `ELYBY_REDIRECT_URI`.
- Общий: `AUTH_SECRET` — длинная случайная строка; `APP_URL` — публичный адрес приложения.

Microsoft должен одобрить приложение для Minecraft Services. Наличие OAuth-приложения само по себе не гарантирует доступ к `authentication/login_with_xbox`. Без одобрения сервис возвращает ошибку, которая показывается пользователю. Пароли не запрашиваются. OAuth использует PKCE, одноразовые state и проверку callback. Токены не возвращаются в публичном API профилей.

## Как запустить игру

Веб-версия не может запустить JVM на компьютере пользователя. На странице сборки нажмите «Установить», затем «Скачать сборку .zip». Распакуйте весь архив, установите Java (см. README внутри архива), запустите `launch.bat` в Windows или `bash launch.sh` в macOS/Linux.

Скрипты используют Java из PATH, `JAVA_PATH` или пути, указанного в настройках. Для Minecraft 1.21+ требуется Java 21; для новых 26.x — Java, указанная в официальных метаданных (включая Java 25). Установщики тяжёлых загрузчиков могут выполняться на первом локальном запуске. Для загрузки файлов нужен интернет.

Офлайн-профиль не является лицензией Minecraft и не работает на серверах с `online-mode=true`. Он использует локальный UUID. Скачанный `voxel-launch.json` содержит приватные данные сессии; не публикуйте архив. Токен Microsoft обновляйте через веб-лаунчер и скачивайте новый архив при истечении.

## Ограничения интеграций

- Один основной загрузчик на сборку. Fabric и Forge не объединяются автоматически; для их совместного запуска нужен отдельный специализированный мод-пак и его инструкции.
- Поддерживается `.mrpack`, а не произвольный ZIP с world/saves или закрытый экспорт CurseForge.
- LiteLoader предназначен для старых версий; Quilt зависит от доступности официального Meta API.
- Каталог модов использует публичный API Modrinth без записи от имени пользователя.
- Voxel не связан с Mojang, Microsoft, Ely.by или Modrinth.
